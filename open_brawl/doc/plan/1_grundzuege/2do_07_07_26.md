# Sprintziel: Vorgaben / Erwartungswerte

> **Hintergrund:** In diesem Sprint geht es darum, die nötigen Grundzüge für ein Würfel-/Regelsystem zu erarbeiten (Grenzen festlegen, Parameter definieren, Variablen identifizieren). Umfangreiche Recherche und Diskussion erforderlich.

---

## 1. Team-Aufstellung (Roster)

- **Kaderstärke (Feldspieler + Ersatzspieler):** 20 Spieler
- **Rollenverteilung:**
  - Primäre Rollen definieren und dokumentieren
  - Sekundäre Rollen definieren und dokumentieren
  - Verteilungsschlüssel (min/max pro Rolle) festlegen
- **Offene Frage:** Wie viele Spieler sind gleichzeitig auf dem Feld?

---

## 2. Spielstruktur

- **Match-Aufbau:** 1 Spiel = 4 Viertel
- **Wechselregel:** Spielerwechsel nur zwischen Vierteln erlaubt
- **Regelmechaniken (zu definieren):**
  - Auszeiten (Anzahl, Dauer, Voraussetzungen)
  - Strafen (Arten, Dauer, Konsequenzen)
  - Toter Ball (Definition, Auslöser, Ablauf)
  - Spielstart / Spielende
  - Siegbedingungen

---

## 3. Spielzug-Dauer

- **Basis-Zugdauer:** Wie lange dauert ein durchschnittlicher Spielzug?
- **Variable Zuglängen:**
  - Welche Züge dauern länger / kürzer als der Durchschnitt?
  - Konzept für variable Zuglängen erarbeiten (z. B. abhängig von Aktionstyp, Entfernung, Modifikatoren)
- **Ziel:** Eindeutige Zeitvorgaben je Aktionstyp, um das Regelsystem darauf aufbauen zu können

---

## 4. Erwartete Spielleistung / Output

- **Statistiken pro Spiel:**
  - Punkte / Score
  - Fouls / Strafen
  - Verletzungen / Ausfälle
  - Ballbesitz / Toter-Ball-Quote
- **Individuelle Spielerstatistiken:**
  - Tore / Assists
  - Tackles / Blocks
  - Strafzeit
- **Offene Frage:** Welche Daten müssen live erfasst werden? Welche reichen Post-Game?

---

## 5. Zielvorgabe & Systemparameter

### 5.1 Verluste, Verletzungen, Tod, Strafen

- **Häufigkeitsdefinitionen:**
  - Leichte Verletzung: ___ pro Spiel (Richtwert)
  - Schwere Verletzung: ___ pro Spiel (Richtwert)
  - Tod: ___ pro Saison (Richtwert)
  - Strafen: ___ pro Spiel (Richtwert)
- **Auswirkungen:** Wie wirkt sich jede Kategorie auf Spieler und Team aus?

### 5.2 Toter Ball

- **Häufigkeit:** ___ pro Viertel (Richtwert)
- **Ursachen:** Foul, Regelverstoß, Aus, Ballverlust
- **Dauer:** Wie lange dauert eine Unterbrechung?

### 5.3 Variablen & Range-System

- **Variablen-Katalog:** Welche Variablen gibt es?
  - Waffen (Reichweite, Schaden, Genauigkeit)
  - Fähigkeiten (Nahkampf, Fernkampf, Athletik, Wahrnehmung)
  - Umgebung (Deckung, Licht, Wetter, Gelände)
  - Status-Effekte (verletzt, erschöpft, gestärkt)
- **Range-Beeinflussung:**
  - Welche Variablen beeinflussen die *Range*?
  - Wodurch wird die *Range* selbst beeinflusst?
  - Wechselwirkungen dokumentieren (z. B. "schlechte Sicht reduziert Waffen-Reichweite um X%")

### 5.4 Zielsetzung

> Es geht darum, generelle Vorgaben zu haben, um darauf ein System zu entwickeln.  
> **Konkret:** Nach diesem Sprint sollen alle Parameter so weit definiert sein, dass ein erstes Würfel-/Regel-System modelliert werden kann.

---

## Abhängigkeiten & Prioritäten

1. **Team-Aufstellung** (Grundlage für Spieler-Rollen)
2. **Spielstruktur** (Rahmenbedingungen)
3. **Spielzug-Dauer** (zeitliche Grundlage)
4. **Systemparameter** (Kern der Systementwicklung)
5. **Output-Erwartung** (Ergebnisdefinition)
